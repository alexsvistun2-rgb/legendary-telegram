# 📚 Личная библиотека

> Управляй файлами книг, конспектами и статусами чтения.

## 📂 Структура
- `42.1_Inbox` — свежезагруженные книги, статьи, PDF
- `42.2_Notes` — конспекты и заметки по книгам

## 🔖 Каталог литературы
```dataview
TABLE status as "Статус", author as "Автор", year as "Год", rating as "Оценка"
FROM "40_Resources/42_Library"
WHERE type = "book"
SORT file.name asc
```

## 🗂 Конспекты
```dataview
LIST FROM "40_Resources/42_Library/42.2_Notes"
SORT file.mtime desc
```

## 🎧 Интеграция с Медиа
> Добавляй плейлисты чтения и звуковые дорожки в `40_Resources/43_Media/43.4_Playlists`.

## ✅ Что сделать
- Импортируй текущие книги в `42.1_Inbox` и задай метаданные.
- Используй шаблон «Библиотека» для создания карточек книги с отзывом и прогрессом.
- Привязывай конспекты к карточке книги через `aliases` и внутренние ссылки.
