# 43_Library — Личная библиотека

## Папки
- **43.1_Books** — файлы книг (PDF, EPUB, аудио).
- **43.2_Notes** — конспекты, читательские дневники, рецензии.

## Рекомендации
- Храни исходники (книги) и конспекты рядом, связывая их ссылками.
- Используй тег `#library` в заметках, чтобы быстро фильтровать.
- Для чтения PDF прямо в Obsidian используй **Media Extended**.
