# 70_Health — Здоровье

## Разделы
- **70.1_Records** — результаты анализов, заключения, рекомендации врачей.
- **70.2_Fitness** — тренировки, беговые сессии и планы восстановления.
  - **70.2.1_Runs** — логи пробежек и интервальных тренировок.

## Идеи по заполнению
- Для анализов создавай заметки с frontmatter:
```
---
date: 2025-10-09
clinic: Инвитро
scope: Биохимия
---
```
- Для тренировок используй шаблон «🏃 Тренировка» из мастер-шаблона (см. ниже).
- Дашборд «Health Dashboard» показывает динамику веса, сна, тренировок и прогресс целей.
