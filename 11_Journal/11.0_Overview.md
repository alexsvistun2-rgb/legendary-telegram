# 11_Journal — Журнал действий

> Фиксирует входящие задачи, делегирование и быстрые записи. Автоматическое наполнение обеспечивает **Auto Note Mover**: достаточно добавить нужный тег, и заметка окажется в целевой папке.

## Структура
- **11.1_Tasks** — оперативные задачи.
  - **11.1.1_Quick** — быстрые дела из шаблона `⚡ Быстрая задача`.
  - **11.1.2_Delegation** — поручения и отслеживание делегированных задач.
- **11.2_Log** — свободные журнальные заметки (создавай вручную при необходимости).

## Советы по использованию
- В шаблоне выбери пункт «⚡ Быстрая задача» или «🤝 Делегировать» — заметка автоматически попадёт в журнал.
- Для ручного переноса добавь тег `#t/quick` или `#t/delegate`.
- В доске GTD используются заметки именно из этих папок, поэтому сохраняй единообразие заголовков.
