# 75_Documents — Личные документы

> Безопасная зона для сканов паспорта, доверенностей, страховок и других важных файлов.

## Структура
- **75.1_Personal_ID** — паспорта, права, загранпаспорта.
- Добавляй подпапки по видам документов (например, `75.2_Contracts`, `75.3_Insurance`).

## Рекомендации по безопасности
- Храни файлы в формате PDF с паролем.
- Используй встроенное поле `sensitive: true` во frontmatter для заметок со сканами, чтобы легко фильтровать их в будущих дашбордах.
