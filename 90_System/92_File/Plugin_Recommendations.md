# 🔌 Recommended Plugins

| Назначение | Плагин | Комментарий |
| --- | --- | --- |
| Pomodoro/Focus | [Focus Timer](https://obsidian.md/plugins?id=focus-timer) | Лёгкий таймер для техники Помодоро, логирует выполненные сессии (интеграция с привычками через теги `habit/pomodoro`). |
| Расширенный Pomodoro | [Pomodoro Scheduler](https://obsidian.md/plugins?id=pomodoro) | Если нужна автоматическая смена сессий и отчёты. |
| Трекер привычек | [Tracker](https://obsidian.md/plugins?id=dataview-tracker) | Строит графики по значениям в файлах; можно связать с папкой `30_Areas/35_Habits`. |
| Form-обновления | [Meta Bind](https://obsidian.md/plugins?id=obsidian-meta-bind-plugin) | Уже установлен; используй формы для обновления значений прямо со страницы. |
| Heatmap | [Heatmap Calendar](https://obsidian.md/plugins?id=heatmap-calendar) | Уже установлен; визуализация привычек и активностей. |
| Медиа-плеер | [Media Extended](https://obsidian.md/plugins?id=media-extended) | Уже установлен; поддерживает плейлисты и просмотр видео/аудио внутри медиатеки. |

> Настройка: включи CSS-сниппеты `card-board-elevated` и `dashboard-widgets`, чтобы стилизовать доски и дашборды.
